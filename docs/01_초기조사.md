## 파일 = 레코드 연속
```
[u32 BE 길이 L][내용 L] … [00 00 00 00]
```
- 내용은 LZ 조각이거나 날것. LZ 조각 = `[u32 BE 원래크기][압축 L-4 바이트]`.
- 대사 파일(C*.BIN · CS*.BIN · SEALION.BIN · D*.BIN …) 320개가 끝까지 이 구조로 걸어진다.

## LZSS (`tools/lz.py`)
- 플래그 1바이트, **LSB 먼저**, 1 = 평문 바이트.
- 참조 2바이트 `a b` → 길이 `(a>>4)+2`, **링 절대 위치** `((a&15)<<8)|b`.
- 링 4 KB, 0 으로 채움, 쓰기 위치 0 에서 시작.
- 압축기는 아직 없음(되쓰기 때 만든다 — 평문만 써도 되는지 = 플래그 전부 1 로 저장 가능).

## 대사 레코드 (`tools/msg.py`)
```
메시지 = [u8 쪽 수 N] + N × ( [u8 쪽 길이 = 글 바이트 + 끝 00] [글…] [00] )
레코드 끝 = 00 00
```
- **길이를 스스로 들고 있다 → 쪽당 255바이트까지 자유**(오프셋 표 없음 — 확인: 쪽 시작 오프셋이 다른 레코드에 없음).
- 글: SJIS 2바이트 · `n 00` 줄바꿈 · `g 숫자2`(대기?) · `z 숫자2` · `o` · `c 숫자` · `i`(선택지 «z00oc4はい　　　oいいえi»). 뜻은 미확정.
- 통계(1장): 메시지 21,556 · 글자 50만(중복 포함) · **서로 다른 쪽 9,825 · 약 32만 자**(중복 제외).
- **창 = 한 쪽 3줄 × 19칸**(원문 줄 폭 분포가 19칸에서 끊김, 4줄 쪽 10개는 예외 확인 필요).
